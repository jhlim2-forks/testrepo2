# 설계

## 구조

- 저장소 루트의 단일 Go 모듈(`module todo`)로 두고, Go 표준 라이브러리와 HTML/CSS/JavaScript만 사용합니다.
- 서버는 `go run .`으로 실행하며 `-listen` 플래그(기본값 `127.0.0.1:8091`)로 주소를 받습니다.
- 서버는 두 가지 일을 합니다.
  - `/` 요청에 `index.html` 한 파일을 제공합니다.
  - `/api/todos`에서 할 일 목록 조회와 추가를 JSON으로 처리합니다.
- 할 일은 서버 메모리의 목록 하나에 추가한 순서대로 담습니다. 식별자는 1부터 시작해 추가할 때마다 1씩 커지는 정수입니다.
- 목록은 여러 요청이 동시에 들어와도 안전하도록 잠금으로 보호합니다.
- 저장소가 메모리이므로 서버 프로세스가 끝나면 목록도 함께 사라집니다.

## API

`docs/requirements.md`의 `## API 계약`에 적은 계약을 그대로 따릅니다.

| 메서드와 경로 | 하는 일 | 성공 응답 | 실패 응답 |
| --- | --- | --- | --- |
| `GET /` | 한 페이지 화면 제공 | `200` + HTML | — |
| `GET /api/todos` | 할 일 목록을 추가한 순서대로 돌려줌 | `200` + `{"todos":[...]}` | — |
| `POST /api/todos` | 할 일 추가 | `201` + `{"id":1,"title":"..."}` | `400` + `{"error":"..."}` |
| 그 밖의 메서드로 `/api/todos` | 처리하지 않음 | — | `405` + `{"error":"..."}` |

제목 검사 순서는 다음과 같습니다.

1. 요청 본문을 JSON으로 읽습니다. 읽을 수 없으면 `400`입니다.
2. `title`의 앞뒤 공백을 제거합니다.
3. 결과가 빈 문자열이면 `400`이며 메시지는 `제목을 입력해 주세요.`입니다.
4. 결과의 글자 수가 200자를 넘으면 `400`이며 메시지는 `제목은 200자까지 입력할 수 있습니다.`입니다.
5. 모두 통과하면 목록 끝에 추가하고 `201`로 추가 결과를 돌려줍니다.

## UI

`index.html` 한 파일로 만듭니다. 모든 문구는 한국어입니다.

- 머리글: `할 일 목록`
- 추가 영역: 제목 입력 칸(안내 문구 `할 일을 입력하세요`)과 `추가` 버튼
- 목록 영역: 할 일을 추가한 순서대로 위에서 아래로 나열합니다. 할 일이 없으면 `할 일이 없습니다.`를 보여 줍니다.
- 오류 영역: 추가가 거절되면 서버가 준 `error` 문장을 입력 칸 아래에 보여 주고, 다음 추가가 성공하면 지웁니다.
- 동작: 화면을 열면 `GET /api/todos`로 목록을 받아 그립니다. `추가` 버튼을 누르거나 입력 칸에서 Enter를 누르면 `POST /api/todos`를 호출하고, 성공하면 입력 칸을 비우고 목록에 새 할 일을 더해 그립니다.

## 수용 기준

- **REQ-01** `GET /`가 `200`과 HTML을 돌려주고, 그 화면에 제목 입력 칸과 `추가` 버튼, 할 일 목록 영역이 한국어로 들어 있다.
- **REQ-02** `POST /api/todos`에 `{"title":"회의 자료 준비"}`를 보내면 `201`과 `{"id":1,"title":"회의 자료 준비"}`를 돌려주고, 이어서 `GET /api/todos`를 호출하면 그 할 일이 목록에 들어 있다.
- **REQ-03** `POST /api/todos`에 `{"title":""}` 또는 `{"title":"   "}`를 보내면 `400`과 한국어 `error` 문장을 돌려주고, `GET /api/todos`의 목록 길이가 호출 전과 같다.
- **REQ-04** 제목이 200자일 때는 `201`로 추가되고, 201자일 때는 `400`과 한국어 `error` 문장을 돌려주며 `GET /api/todos`의 목록 길이가 호출 전과 같다.
- **REQ-05** 할 일 세 건을 차례로 추가한 뒤 `GET /api/todos`를 호출하면 `todos` 배열의 제목이 추가한 순서와 같다.
- **REQ-06** 새로 만든 서버에 `GET /api/todos`를 호출하면 `todos`가 빈 배열이다.

## 위험

- 메모리 저장이므로 서버를 다시 켜면 입력한 할 일이 사라집니다. 첫 버전에서 받아들이는 제약이며, 화면에도 데이터가 유지된다는 기대를 주는 문구를 두지 않습니다.
- 200자 한도를 바이트 수로 세면 한글 제목이 70자 정도에서 막힙니다. 글자 수로 세어 이를 피합니다.
- 입력한 제목을 화면에 그릴 때 HTML로 해석하면 의도하지 않은 내용이 실행될 수 있습니다. 제목은 항상 글자로만 넣습니다.
- 여러 탭에서 동시에 추가하면 한 탭의 화면이 오래된 목록을 보여 줄 수 있습니다. 첫 버전은 화면을 다시 열어 맞추는 수준으로 둡니다.

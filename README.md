# 할 일 관리 웹앱

작은 할 일(TODO) 관리 웹앱을 기능 단위로 조금씩 만들어 가는 프로젝트입니다.

- 진행 상황: [프로젝트 보드](https://github.com/orgs/jhlim2-forks/projects/4)
- 개발 근거 문서와 문서 규칙: [docs/README.md](docs/README.md)

## 일하는 방식

요청 하나를 이슈 하나로 남기고 보드의 `접수` 컬럼에 올립니다. 팀이 요청을 근거 문서와 대조해, 정의가 없으면 문서 PR을 먼저 열고 정의가 있으면 바로 구현 PR을 엽니다. 한 이슈의 PR은 차례로 하나씩 열립니다.

- `main`에 병합된 문서 없이 개발하지 않고, 승인자의 승인 없이 문서나 결과를 반영하지 않습니다.
- 승인은 PR 병합입니다. 문서 PR 병합은 정의 승인, 구현 PR 병합은 결과 승인, 릴리스 PR 병합은 배포 승인입니다. `main`은 `자동 검사`를 통과한 PR만 병합할 수 있습니다.
- 검토할 PR은 승인자에게 리뷰 요청으로 알립니다. 고칠 점은 PR 리뷰의 **Request changes**로 남깁니다.
- 사람이 정할 일은 이슈 댓글에서 승인자를 @멘션해 묻고 담당자로 지정합니다. 답할 때는 봇 멘션(`@symphony-bot-dev`)을 함께 적습니다. 멘션이 없는 댓글은 의견으로 보고 자동화가 반응하지 않습니다.
- 작업을 멈추려면 이슈에 `일시 중지` 라벨을 붙이고, 그만두려면 이슈를 *Close as not planned*로 닫습니다.

## 실행

아직 구현이 없습니다. 첫 기능이 병합되면 실행 방법을 이곳에 적습니다.
